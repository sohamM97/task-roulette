## Testing Caveats

- **Async screens with loading spinners**: `pumpAndSettle` hangs on `CircularProgressIndicator`. Use the `pumpAndLoad` pattern: `runAsync(Future.delayed(10ms)) + pump()` in a loop (20 rounds).
- **sqflite in widget tests**: Must use `databaseFactoryFfiNoIsolate` (not `databaseFactoryFfi`) because `testWidgets` runs in `FakeAsync` where isolate-port I/O stalls.
- **DB inserts in widget tests**: Wrap in `tester.runAsync(() async { ... })`.
- **MultiProvider for screens**: Screens with `ProfileIcon` need `AuthProvider` and `SyncService` in the provider tree.
- **SyncService and FirestoreService take injected fakes**: `SyncService(auth, firestore:)` and `FirestoreService(client:)`. Reuse the fakes in `sync_service_test.dart` (`_FakeAuthProvider`, `_FakeFirestoreService`) rather than writing new ones.
- **Code that calls top-level `http.post`/`http.get`** (e.g. `AuthService`): wrap the call in `http.runWithClient(..., () => MockClient(...))`.
- **Parallel `flutter test` runs in one checkout can segfault** ("Shell subprocess crashed with segmentation fault"), likely because each run rewrites `build/native_assets/linux/libsqlite3.so` while another process has it loaded. Run one `flutter test` at a time per checkout.
- **A DB reopened inside FakeAsync must be closed in the test body**, not `tearDown`, or the runner hangs (see the Restore test in `backup_service_test.dart`).
